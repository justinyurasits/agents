What's an agent

An agent is a language model in a loop. Each turn it decides the next step, usually a request to use a tool. Code carries the step out and hands back the result, and it repeats until the model says the job is done.

  1. The model decides the next step
  2. Code runs the tool it asked for
  3. The result goes back to the model
  4. Repeat until the model says it's done

Claude decides; Python executes. In this agent the model is Claude and the code is Python. Claude never runs anything itself: it can only ask, and Python decides whether and how to carry the request out.

How this agent works

It reads a job posting and rates it for one candidate. Four parts take part in every run:

Python
The agent loop. It calls Claude, runs the tools Claude asks for, and keeps the conversation.
Claude
The model in the main conversation. It reads the posting and every result so far, then asks for a tool or writes its final answer.
The tools
Python functions that do the work. Claude picks them by name; Python runs them.
The grader
A second, separate call to Claude, made from inside evaluate_job. It answers one yes/no question about the work, has no tools, and never sees the main conversation.

The loop. Each pass, Python sends the whole conversation to Claude. If Claude asks for tools, Python runs them, adds the results to the conversation, and sends it again. When Claude answers without asking for a tool, the run ends. The conversation is the agent's only memory.
